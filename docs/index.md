# chancellor documentation

Chancellor keeps structured records (decisions, requirements, specifications) in one validated data
model and renders them into per-record files plus the core documents that index them.

```{note}
This repository currently holds the package skeleton, toolchain and CI. The renderer, its
templates and its tests arrive with the source migration; pages below mark what is documented
then.
```

The documentation has two parts:

- [User documentation](user/index.md) is for people who install chancellor and use it on their own
  records.
- [Developer documentation](developer/index.md) is for people who work on chancellor itself.
